# Evidence

Evidence is the original article material shown to a model and later to a human
reviewer. The original content is authoritative; model summaries never replace
it.

## Text

Normal article text is segmented once into canonical paragraph-aware chunks.
Rule matching and PhysBERT retrieve from the same collection. A shared chunk is
one `TextEvidence` with multiple retrieval-method records.

## Tables

A `TableEvidence` contains enough original structure to interpret a value:
caption, headers, rows, units, and footnotes. Large tables may be sliced, but
each slice repeats its caption and headers.

## Figures

A `FigureEvidence` always retains the image path and original caption. Vision
output is derived metadata, not a replacement for the image. Graph estimates
retain qualifiers such as `approximately` and are not silently merged with
explicit text values.

## Equations

An `EquationEvidence` contains the original equation and nearby original text.
It produces a numerical Fact only when the material, variables, value, and unit
are supported by that evidence.

## Minimal identity

IDs are generated by the software. A user does not manage them. They exist only
to prevent duplicate model calls and connect Facts back to original evidence.
