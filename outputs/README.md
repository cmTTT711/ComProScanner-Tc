# Outputs

Only durable, reviewable artifacts belong here.

- `gold/`: human-reviewed reference facts and review workbooks.
- `runs/`: final or reproducible prediction runs. New runs use one directory
  per run id.
- `metrics/`: evaluation output derived from Gold and predictions.
- `literature/`: discovery candidates, shortlists, and download manifests.
- `reports/`: project reports and final presentations.

Temporary traces, per-paper debugging files, caches, rendered slide previews,
PDF inputs, and API credentials do not belong in this directory.
